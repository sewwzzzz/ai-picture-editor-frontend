### OOP与FP的区别

- OOP：类、结构/封装

### 脚本、样式表加载

- 内联脚本 同步下载与执行

- 外链样式表 同步下载与执行

- 模块脚本(defer) 同步下载与异步执行

- Vite构建时原本写在 <body> 里的标签会按固定规则注入到 <head> 末尾

```
head 方案：
HTML 解析 ──┐
   ├─ 刚读到 head 的 script → 开始下载模块图（与渲染并行）
   └─ DOM 渲染
DOM 就绪 → 执行脚本
（下载更早开始，整体 TTI 更短）

body 末尾方案：
HTML 解析 ──→ 几乎解析完才"看到" script → 开始下载模块图
DOM 就绪 → 执行脚本
（下载被推迟到 HTML 接近解析完才发生）

```
