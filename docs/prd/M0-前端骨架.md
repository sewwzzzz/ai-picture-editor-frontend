## 一句话功能

- 搭建前端开发基础架构。

## 用户故事

- 作为 前端开发者，我要 搭建前端开发基础架构，以便 后续模块可以进行高效开发。

## 要做的事（5–15 条，必须可追溯到原项目的真实功能）

- [ ] 安装 Vite + React + TS 的基础依赖，初始化项目

- [ ] 规划目录结构

- [ ] 搭建路由框架

- [ ] 搭建状态管理框架

- [ ] 编写传输层，统一处理请求错误与认证失败

- [ ] 配置开发代理，与后端使用健康检查接口进行联调

- [ ] 适配不同主题的样式结构，确保正常切换

## 不做的事（3–8 条，必须具体到可判定）

- [ ] 不进行后续模块页面的路由编写

- [ ] 不编写后续页面的前端

- [ ] 请求层仅接入/api/health

## 验收标准（做到什么算完成）

- 正常路径：后端应用正常运行的情况下，开发者运行构建命令后，可以在本地浏览器看到页面，能完成简单主题切换、路由跳转。

- 异常路径：后端没有启动应用的情况下，本地浏览器会出现合适的错误提示，而不是仅展示空白页

## 后端理解要求（已提供，仅需理解）

> 目标：做前端时顺手搞懂，最终能**口头讲清**，用于面试。

- 涉及的接口：`/api/health`
- 需要讲清的链路：前端调用健康检查接口 -> 后端返回健康检查结果 -> 前端后续业务
- 面试官可能追问：
    + 前端为什么需要调用健康检查接口
    + 前端什么时候调用健康检查接口
    + 前端如何处理健康检查接口的返回结果或者根据结果做什么决策
